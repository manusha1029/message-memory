# 🧠 Message Memory

> A private, local-first AI memory layer for conversations.

Message Memory helps turn important information buried inside conversations into searchable and persistent memories.

## ✨ Features

- 📥 Import WhatsApp `.txt` conversation exports
- 🔎 Search messages by keyword or sender
- 🤖 Ask natural-language questions about conversations
- 📚 Get answers with supporting chat evidence
- 🧠 Extract useful memories using AI
- 🗂️ Organize memories into categories
- 🔍 Search saved memories
- ✏️ Create and edit memories
- 🗑️ Delete memories
- 🔒 Local-first privacy-focused design

## 🤖 AI

Message Memory uses:

**Qwen 2.5 0.5B ONNX**

The application provides in-browser AI-powered question answering and memory extraction.

## 🔐 Privacy

Message Memory is designed as a private, local-first application.

The application processes imported conversations in browser memory.
